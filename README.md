# Нулевой протокол

Сюжетная учебная игра об алгоритмах и условиях на Pascal. Игрок восстанавливает системы города Ветвление, выбирает фрагменты кода и получает один из шести исходов.

**Играть:** https://Git72-devst.github.io/Protocol_Zero/

## Запуск

Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages. Установка пакетов и сборка не нужны. Прогресс сохраняется локально в браузере.

## Правила

- В начале доступно 8 делений энергии. При активной утечке каждые 5 секунд теряется одно деление.
- Первое задание — отдельный алгоритм ремонта. Правильный ремонт закрывает утечку навсегда.
- Можно продолжить с активной утечкой; после выхода из начального ремонта вернуться к нему нельзя.
- Основные задания не останавливают утечку. При нуле энергии игра сразу завершается.
- Пять основных заданий посвящены сравнению, `or`, `and`, порядку действий и `if ... then ... else`.
- На шестом этапе выбирается режим Ядра. Финал зависит от решений и состояния города.

## Файлы
- `index.html`, `styles.css`, `app.js` — интерфейс браузерной игры.
- `engine.js` — игровое состояние, таймер утечки, проверка решений и выбор концовки.
- `pascal/zero_protocol_abc.pas` — консольная версия для PascalABC.NET.
- `pascal/zero_protocol.pas` — вариант для Free Pascal. В нём прошедшее время учитывается при вводе, поэтому обновление энергии отображается после нажатия Enter.
- `tests/engine.test.cjs` — проверки игровой логики.

Учебные фрагменты в браузерной игре написаны на Pascal; сама браузерная версия работает на JavaScript. В папке `pascal` находится отдельная реализация на Pascal.

## Проверка логики

При установленном Node.js выполните из папки репозитория:

```sh
node --test tests/engine.test.cjs
```

## Публикация

GitHub Pages публикует ветку `main`, папку `/(root)`. Файл `.nojekyll` включает раздачу готовых статических файлов. Чтобы обновить игру, сохраните изменения, сделайте commit и нажмите **Push origin** в GitHub Desktop.
